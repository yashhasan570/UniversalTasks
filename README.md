# Universal Tasks

Self-hosted to-do list and project task management: organize tasks into projects, with labels, comments, reminders, recurring tasks, files, and team collaboration.

## Features

- Projects, lists, and kanban boards with drag-and-drop
- Tasks with due dates, reminders, recurring schedules, labels, assignees, attachments
- Calendar view, Gantt view, table view
- Team sharing with fine-grained permissions
- REST API, CalDAV, and MCP support for clients and integrations
- Third-party auth (OpenID Connect), 2FA

## Install

- Download the binary for your platform and run it, or
- `docker compose up` with the provided Dockerfile, or
- build from source: `mage build` (Go backend + Vue frontend)

Configuration is file- or environment-based: every `UNIVERSALTASKS_*` setting can be set in `config.yml` or as an environment variable.
